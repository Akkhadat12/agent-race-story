# The Agent Race

An interactive, desktop-first 2D visual story about AI agents in cyber offense and defense. The images are conceptual illustrations, not records of actual incidents or quantitative diagrams.

## Controls

- Click the highlighted object in each scene to continue.
- Space advances one scene. Held key repeats are ignored.
- R returns to the cover from any scene, including during transitions.
- The final scene holds until the presenter presses R.

## Local preview

Serve this directory as a static site. `index.html` is the entry point. There is no build step.

## Artwork

Original AI-generated conceptual artwork was created for this project. Named organizations and measured statistics are intentionally absent from the visual scenes. The Thai reading documents and scene guide provide the evidence and limitations.
